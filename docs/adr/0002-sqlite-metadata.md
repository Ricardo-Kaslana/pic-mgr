# ADR-0002: SQLite 存储元数据

**日期:** 2026-06-07
**状态:** 已接受

## 背景

图片的标签、备注、评分等元数据需要持久化存储。

## 决策

使用 SQLite (rusqlite + bundled)，所有元数据只写数据库，不修改原始图片文件。

## 理由

- 单文件数据库，零配置
- FTS5 支持全文搜索
- WAL 模式支持并发读写
- `bundled` feature 自带编译好的 SQLite，无需系统依赖

## 后果

- 数据库文件在应用数据目录，与工作区分离
- 工作区可自由移动/重命名（使用相对路径）
- 数据库损坏风险低，但需定期备份
